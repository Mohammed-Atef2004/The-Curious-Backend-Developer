## ✨ About the Project

> **The Curious Backend Developer** is an educational repository built for developers who aren't
> satisfied with just *writing* code — they want to understand **what happens under the hood**.
> It covers the entire **.NET ecosystem**: from C# fundamentals, through the depths of CLR,
> ASP.NET Core, EF Core, and LINQ, all the way to software architecture via Domain-Driven Design,
> plus clear roadmaps and practical interview questions.

The goal is not just to make you a Backend developer — it's to make you **a developer who understands every line they write.**

## 📚 What's Inside Each Section?

### 1. 📚 .NET Books
A collection of the most respected reference books for learning the .NET ecosystem:

| Book | Short Description |
|---|---|
| **C# in Depth (3rd Edition)** — Jon Skeet | Deep understanding of C# language features and their evolution |
| **CLR via C# (4th Edition)** — Jeffrey Richter | How the Common Language Runtime really works |
| **ASP.NET Core in Action** | Building modern web apps with ASP.NET Core |
| **C# 12 in a Nutshell** — Joseph Albahari | A complete reference for C# 12 and the .NET environment |
| **Patterns, Principles, and Practices of DDD** — Scott Millett | Applying Domain-Driven Design in practice |

> ⚠️ Books are included for personal educational purposes only. Please support the authors by purchasing original copies when available.

### 2. ⚙️ ASP.NET Core Internals
Notes covering:
- **Pipeline & Middleware** — How a Request flows through the Middleware chain
- **Dependency Injection** — How DI containers are built in ASP.NET Core
- **Hosting Model** — Kestrel, IIS, Out-of-Process Hosting
- **Endpoint Routing** — Conventional vs Attribute Routing
- **Filters & Middleware** — When to use which

---

### 3. 🔬 C# Internals
A look behind the code you write:
- **Value Types vs Reference Types** — Where data lives in memory (Stack vs Heap)
- **Garbage Collection** — GC generations and how memory is reclaimed
- **async / await** — The State Machine generated by the compiler
- **Delegates, Events & Multicast** — How they work underneath
- **Pattern Matching & Records** — Modern C# features

---

### 4. 🗄️ Database Internals
Concepts that level up any Backend developer:
- **Indexing** — B-Tree, Clustered vs Non-Clustered Indexes
- **Transactions & Isolation Levels** — Read Committed, Snapshot, Serializable
- **Concurrency Control** — Optimistic vs Pessimistic
- **Query Execution Plans** — Reading execution plans to improve performance
- **Normalization & Denormalization** — When to use each

---

### 5. 🧩 Domain Driven Design
Fundamentals of building maintainable complex systems:
- **Ubiquitous Language** — A shared language between team and business
- **Bounded Contexts** — Splitting the system into independent contexts
- **Entities, Value Objects, Aggregates** — Building blocks of the Domain
- **Repositories & Domain Events** — Data access patterns and inter-aggregate communication
- **Strategic vs Tactical Design** — The difference between the two

---

### 6. 🔄 EF Core Internals
Understanding what happens between C# code and the database:
- **Change Tracking** — How EF Core tracks changes to Entities
- **Query Translation** — How LINQ becomes SQL
- **Lazy vs Eager vs Explicit Loading** — Data loading strategies
- **Concurrency Tokens** — Managing concurrency in EF Core
- **Migrations** — How Migrations are built and applied

---

### 7. 🔗 LINQ Internals
- **Deferred Execution** — Why a query isn't executed when written
- **IEnumerable vs IQueryable** — The core difference and its performance impact
- **Extension Methods** — How LINQ is built on top of them
- **LINQ to Objects vs LINQ to Entities** — Execution differences
- **Performance Pitfalls** — Common mistakes and how to avoid them

## 🚀 How to Use This Repository

1. **Start with the Roadmap** 🗺️ — Open the `RoadMaps` folder to understand the correct learning order.
2. **Read the conceptual chapter first** 📖 — From the `.NET Books` folder to build theoretical foundation.
3. **Move to the Internals** 🔬 — Pick the topic that interests you (C#, ASP.NET Core, EF Core, ...).
4. **Apply what you've learned** 💻 — No reading without code; open your IDE and experiment.
5. **Test your understanding** ❓ — Review the questions in `Interview Questions` to evaluate yourself.

> 💡 **Tip:** Don't jump randomly between topics. Follow the order suggested in the Roadmap for cumulative, consistent understanding.
